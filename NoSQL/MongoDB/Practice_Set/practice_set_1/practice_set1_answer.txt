    Q64. Explain why estimatedDocumentCount() ignores filters.

        Answer

        estimatedDocumentCount() reads the collection metadata instead of scanning documents.
        Therefore, any filter passed to it is ignored and it always returns the estimated total
        number of documents in the collection.

    -> Interview Challenge

    Q71. Difference between countDocuments() and estimatedDocumentCount().

        Answer

        countDocuments()

            -> Returns exact count.
            -> Supports filters.
            -> Reads matching documents or indexes.

        estimatedDocumentCount()

            -> Returns estimated total count.
            -> Ignores filters.
            -> Reads collection metadata only.

    ------------------------------------------------------

    Q72. Difference between limit() and skip().

        Answer

        limit()

            -> Limits the number of returned documents.

        skip()

            -> Skips the specified number of documents before returning results.

    ------------------------------------------------------

    Q73. Why is limit() usually used with sort()?

        Answer

        Sorting ensures the documents are ordered first.
        limit() then returns the required top records from that ordered result.

    ------------------------------------------------------

    Q74. Why is countDocuments() a Collection method instead of a Cursor method?

        Answer

        Because countDocuments() counts documents directly from the collection.
        find() returns a Cursor, which is used only for iterating over query results.

    ------------------------------------------------------

    Q75. Difference between distinct() and SQL DISTINCT.

        Answer

        MongoDB distinct()

            -> Returns unique values of a field.

        SQL DISTINCT

            -> Removes duplicate values from selected column(s).

        Both are conceptually equivalent.

    ------------------------------------------------------

    Q76. Difference between distinct() and Aggregation $group.

        Answer

        distinct()

            -> Returns unique values only.
            -> No calculations.

        Aggregation $group

            -> Groups documents.
            -> Supports Count, Sum, Average, Min, Max and other aggregations.

    ------------------------------------------------------

    Q77. Why can't we write:

        db.users.find().countDocuments()

        Answer

        Because find() returns a Cursor.
        countDocuments() is a Collection method, not a Cursor method.

    ------------------------------------------------------

    Q78. Explain the pagination formula with an example.

        Answer

        Formula

            skip = (pageNumber - 1) × pageSize

            limit = pageSize

        Example

            Page Number = 3
            Page Size = 5

            skip = (3 - 1) × 5 = 10

            db.users.find()
            .skip(10)
            .limit(5)

    Q80. Explain the execution order of the following query:

        db.users.find({ age: { $gt: 25 } })
                .sort({ age: -1 })
                .skip(2)
                .limit(3)
                .project({ name: 1, age: 1, _id: 0 })

        Answer

        Execution Order

            1. Filter documents where age > 25.
            2. Sort the matching documents by age in descending order.
            3. Skip the first 2 documents.
            4. Return the next 3 documents.
            5. Display only name and age, excluding _id.
